# Currency Converter 💱

A simple and interactive **Currency Converter** built using **HTML, CSS, and JavaScript**. The project uses a currency exchange API to fetch exchange rates and convert amounts between different currencies.

## 🚀 Features

* Convert between multiple currencies
* Fetches exchange rates using an API
* Dynamic currency selection
* Displays currency flags
* Supports user-defined amounts
* Displays the converted amount instantly
* Automatically loads an initial exchange rate

## 🛠️ Technologies Used

* **HTML** – Structure of the application
* **CSS** – Styling and layout
* **JavaScript** – Application logic and DOM manipulation
* **REST API** – Fetching currency exchange rates

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Immortal1544/Currency-Converter-Mini-Project-.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Select the currencies, enter an amount, and click **Get Exchange Rate**.
